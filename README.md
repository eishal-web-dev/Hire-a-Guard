# HireGuard

Interactive security-agency marketplace demo built for Ashes Stack.

## Features

- Responsive conversion-focused landing page
- Premium 3D guard artwork and motion effects
- Client security-request workflow
- Verified guard matching and selection
- Agency operations dashboard preview
- Identity and licence verification presentation

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repository into Vercel. It is configured as a standard Next.js application and requires no environment variables for the demo.
